# 析字 Xizi

一个 Windows 五笔（86 版）输入法。目标是把三件市面五笔普遍缺失的事做对：

1. **候选按使用习惯浮动，但不是「选一次就置顶」** —— 频次 × 时间衰减 + 晋升阈值，偶用一次只挪一位，长期高频才真正上浮。
2. **拼音五笔混输不混排** —— 判定为拼音的段只出拼音候选，同时把该字的五笔码显示在旁边，边打边学。
3. **词组候选带 emoji** —— 可选，映射可自己改。

> 项目处于 **M0 完成** 阶段：数据装配与排序引擎已验收，**还没有可安装的输入法**。
> 现在能做的只有「在终端里打字验证引擎行为」，见下文。

## 现在能试什么

需要 Rust 工具链（1.83+）。

```powershell
# 1) 拉原始码表（约 1.5 MB，只需一次）
powershell -ExecutionPolicy Bypass -File tools\fetch-data.ps1

# 2) 装配方案数据
powershell -ExecutionPolicy Bypass -File tools\gen.ps1

# 3) 在终端里打字
cargo run --release -p xizi-cli -- repl
```

REPL 里一行就是一次完整按键序列：

```
> v          → 发（一级简码）
> vbg        → 好（全码）
> fpgc       → 45 个重码字，按码表权重排序
> 5          → 选第 5 个并记一次使用
> :explain   → 看每个候选的 n / Δt / 学习分 / 综合分
> :help      → 全部命令
```

选过的词下次会按 §5 规则浮动：单次使用只前进一位，想越过第一名要持续使用（默认门槛是 1.5 倍）。

码表作为独立授权的数据文件随包分发，与代码许可分离；不修改、不并入代码。

## 已知限制

- 仅 Windows、仅五笔 86 版（两者都留了扩展钩子，但 v1 不做）。
- 完全离线：程序自身不发起任何网络请求。
- `z` 开头的码不进码表（`z` 是五笔万能键）。
- 字根拆解（「好 = 女 + 子」）**v1 不提供**：公开拆字数据是部件级而非字根级，实测重编码一致率仅 1.19%，见 `docs/design/probe-report.md`。v1 只显示五笔码。
