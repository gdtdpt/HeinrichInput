# 亨利五笔 HeinrichInput

Windows 上的五笔 86 输入法。**候选顺序跟着你的手变**，**拼音能和五笔混着打**，
**字根和码位随时能查**。

---

## 三件事跟别的五笔不太一样

| 常见的不顺手 | 这里怎么做 |
|---|---|
| 选过一次的词立刻跳到第一，用几天顺序全乱 | **用得多的词才慢慢上浮**。第一次上屏不计分；第二次起每用一次加一点，久不用会退（半衰期 45 天）。连打同一个码时那一屏的顺序会冻住，不会按着「2」突然换了人 |
| 拼音候选和五笔候选挤在一屏，不知道该按哪个 | **一次输入只判定一种语言**：五笔占首屏，拼音候选接在后面、淡一档（反过来也一样）。判定不如你意时加一个 `'` 就强制走拼音 |
| 早忘了「女刀九臼山朝西」是哪一键 | 拼音打出的候选旁边带五笔码；按 `Ctrl+Alt+N` 弹出**键位图**，把这条候选的码逐位展开成键帽 |

词库是 13.6 万条的五笔 86 表 + 6.5 万条的拼音词库，全部**离线**——程序不发任何网络请求。

## 安装

需要 Windows 10 x64（或更新）。

### 用安装包（推荐）

1. 双击 `HeinrichSetup-1.1.3.exe`，默认装到 `C:\Program Files\HeinrichInput`。
   安装器会放好文件、注册输入法、跑四项自检，并建好开始菜单里的「亨利五笔 设置」。
2. **不用先关掉正在运行的程序**：安装器会把被占用的文件改名腾位，装完照常可用。
   但已经开着的程序（微信、浏览器、编辑器）仍跑着旧代码，**重启它们**才会用上新版；
   装完如果还有这样的程序，安装器会告诉你具体是哪几个。新打开的程序立刻就是新版。
3. 在语言栏或 `Win+空格` 里切到「亨利五笔」。

批量部署用静默安装：

```powershell
.\HeinrichSetup-1.1.3.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART
```

卸载走「设置 → 应用 → 亨利五笔 → 卸载」。**卸载默认保留你的词库、emoji 绑定与学习库**
（`%APPDATA%\Heinrich` 与 `%LOCALAPPDATA%\Heinrich`），重装后接着用——这些是你自己
攒下来的东西，卸载程序是卸的。

要连数据一起删，在卸载向导里勾上那个选项；静默卸载则显式加 `/PURGE`：

```powershell
& "C:\Program Files\HeinrichInput\unins000.exe" /VERYSILENT /SUPPRESSMSGBOXES /PURGE
```

> 卸载时若有程序正加载着 `heinrich_win.dll`（微信、浏览器、编辑器都可能），
> 那个 DLL 删不掉，Windows 会安排在重启后删除。想立刻清干净就先关掉它们再卸载。
> **这种情况下别在重启前重装**：那条「重启后删除」的登记可能把新装的文件一起删掉。
> 安装器会检测到并提醒你；真遇到了，重启后再跑一次安装包即可复原。

### 用绿色目录（开发态 / 不想装）

1. 把整个程序目录放到一个固定位置（例如 `C:\Heinrich`）。
   `heinrich_win.dll` 与 `heinrich-server.exe` **必须同一个目录**——前者靠「同目录」找后者。
2. 运行 `heinrich-setup.exe install`，在 UAC 窗口点「是」。
3. 同上第 2、3 步。

```
heinrich-setup.exe status       # 查注册状态（不需要管理员）
heinrich-setup.exe uninstall    # 反注册（不动用户数据）
heinrich-setup.exe purge        # 删除词库 / 配置 / 学习库（不可恢复）
heinrich-setup.exe shortcut     # 补开始菜单快捷方式（不需要管理员）
```

目录里另外几个 exe 是开发与验收工具（`heinrich-cli` 校验码表、`heinrich-cand-preview`
预览窗口、`heinrich-gen` 装配数据），日常使用用不到，见 [`docs/dev-guide.md`](docs/dev-guide.md)。

### 怎么确认装的是哪一版

打开「亨利五笔 设置」，**标题栏就带着版本号**（例如 `亨利五笔 · 设置 · v1.1.3`）；
命令行也能查：

```powershell
& "C:\Program Files\HeinrichInput\heinrich-setup.exe" status   # 看「版本」那一行
```

版本号三段 `主.次.补丁`：**补丁位**是修 bug / 调行为（覆盖安装即可，配置与词库照旧），
**次位**是新增了你能看见的功能，**主位**变化才需要迁移旧配置。升级只认「装一次」——
不用关程序，但**装之前就开着的程序会继续用旧版**，重启它们才切换。

## 打字

| 按键 | 作用 |
|---|---|
| `a`–`y` | 输入五笔码，最多 4 码；有拼音词库时也可以是拼音（不受 4 码限制） |
| `空格` / `回车` | 上屏当前候选 |
| `1`–`9` | 选本页第 n 条 |
| `-` `=` 或 `←` `→` `PgUp` `PgDn` | 翻页 |
| `Esc` | 取消这次输入，不留残字 |
| `退格` | 逐码回退 |
| 单击 `Shift` | 切换中英。英文模式下所有键都交还程序本身 |
| `Shift`+字母 | **没有候选窗时**：临时打一个大写字母，不切模式；**候选窗出来后**：大写字母原样进缓冲——大写匹配不到任何候选，单击 `Shift` 切走时整串原样上屏（如输入 `gA` 再单击 `Shift`，上屏 `gA`；中文态不会把大写直接上屏，D97/D98） |
| `'` | 分段标记：`hao'` 只出拼音候选；`hao'vb` 前一段拼音、后一段五笔，只出词典里有的真词（如 `hao'ktn` → 好吃），chip 标在拼音那个字后面 |
| `z` | 万能学习键：`vbz` 列出 `vb` 开头的字，每条都带五笔全码 |
| `Ctrl+Alt+1`–`9` | 弹出本页第 n 条候选的**键位图** |

中文模式下这些标点会自动转成全角，并且和前面的字一起上屏：`, . ; /` → `，。；、`，
按下 `Shift` 时依次是 `《》：？`，另有 `Shift+1` / `Shift+9` / `Shift+0` → `！` `（` `）`、
`Shift+6` → `…`（单个省略号，要「……」按两次）。

## 码提示与键位图

- **码提示**：用拼音查出来的候选，右下角带一个灰底小字，是这个字的五笔码。
  比如打 `hao`，拼音候选「好」旁边是 `vbg`。用它边打边记码。
- **键位图**：候选窗显示时按 `Ctrl+Alt+N`，把第 n 条候选的码逐位摊开——
  每一位一张键帽，写着那个键上的全部字根（变体淡一档）；
  底部一行提示「不足 4 码时末位可能是末笔识别码」。
  上屏、`Esc`、切窗口、继续打字都会把它收掉。
- **它只回答「这个键上有哪些字根」，不回答「这个字怎么拆」**——后者要笔顺与字型数据，
  机器拆出来的东西大半是错的，所以这里宁可不给。用拼音打 `hao`、看「好」的码是 `vbg`，
  再按 `Ctrl+Alt+1` 看 v / b / g 三个键上的字根，最后一步由你自己完成。
- 用的不是 `Ctrl+Shift`：那是 Windows 切换输入法的热键，按一次弹图就把输入法切走了。
  同理，没有候选窗时这些组合一律还给程序本身。

## emoji 候选

打 `wqvb` 出的是 **`1 你好　2 👋　3 您好 …`**——emoji 自己占一个位号，按 `2`（或者点它）
**上屏的就是那枚 emoji**。文字是文字，emoji 是 emoji，两者互不干扰：

- 按 `1` / 空格：还是正常的「你好」；
- 按 `2` / 点图标：文档里出现 👋；
- 每个有 emoji 的词后面都会跟一条，编号紧挨着它。

几条规矩：

- **内置表只挂词组**。单字候选一行好几个（`vb` 下面是 好 / 妈 / 姐 …），每条后面
  再跟一枚 emoji，行宽会翻倍——所以默认只有 `你好`、`好吃`、`好运` 这些词组有。
  **想给单个字挂也可以**（D85）：在设置窗口的 emoji 页，「绑到」框里直接写那个字、选一枚
  emoji、点「保存绑定」；或在用户层里写 `word = "好"`——那是显式意图，照办，代价是那个字
  所在的候选行会变宽。
- **一个词最多一枚**，同一个 emoji 可以挂在很多词上。
- 内置表约 2400 条，来自 Unicode 官方的中文注音表（CLDR）与词库求交，不是手写的。
  每枚 emoji 在 CLDR 里带几个中文关键词（比如 👍 是 `赞 / 顶 / 大拇指`）——哪个关键词本身
  是词库里的词，就给它挂这枚 emoji；同一个词被多枚 emoji 抢时，按「关键词排名 → 码位」
  取最靠前的那枚，所以结果是确定的。
- **本机字体画不出来的会自动跳过**：Win10 自带的 emoji 字体到 Emoji 12 为止，更新的那些
  （例如 Emoji 13 的 🫂）在候选窗里只会是一块方块，所以装载时就整条丢掉了。换台新系统
  重启输入法，能用的会更多。
- 选中 emoji **不算「打过这个词」**，不会影响候选排序与学习数据。

想改绑、想自己配一套，就编辑用户层 `%APPDATA%\Heinrich\emoji.user.toml`（**保存即生效，不用重启**）。

这个文件**默认并不存在**——它只是可选的覆盖层，装完不会自动生成。两种改法：

- **设置窗口的 emoji 页**（推荐）：编辑面板那一行是两个框——**「绑到」**里写要挂 emoji 的词或字
  （`好`、`好评`），也可以写五笔码（`vb`），程序自己认；**「emoji」**里粘一枚，或点
  「**浏览 emoji…**」弹出**按分类排的网格**（表情 / 手势 / 爱心 / 动物 / 食物 / 活动 / 出行 /
  物品 / 符号 / 其他），点一枚自动填回、滚轮翻页、`Esc` 或右上角 `×` 关掉，本机画不出来的不会出现在
  网格里。点「**保存绑定**」立刻生效——**不用先在列表里找到那个词**，这就是给单字挂 emoji 的路。
  改已有的绑定：在列表里点一行，两个框自动填好，换一枚 emoji 再点「保存绑定」即可。
  输入不合法（空的 / 不是 emoji / 粘了多枚 / 那个词根本打不出来）不会保存，编辑面板第一行用红字
  说明该改什么。列表上方还有「**只看我绑的**」，一亮就只剩你自己改过的行（已改绑 / 已停用 / 新增）；
  emoji 列与候选窗、网格一样是彩色字形。右上角是「停用 emoji 候选」总开关。

  **要绑的词是自己加进词组页的？**（比如「小红书」）先在「词组」页加好、保存，再回来绑就行——
  两页看到的是同一份词库。词只在词库里才有候选，emoji 是跟在候选后面的一条，所以「打不出来
  的词」绑了也永远不出现。

  **想撤掉一条绑定，分两种做法**（两个按钮就在下面一排）：

  | 想干什么 | 点哪个 | 结果 |
  |---|---|---|
  | 先别让它出现，绑定留着 | **停用** | 行变淡、状态写「已停用」，候选里不再挂这枚；同一个按钮再点一次就是「启用」 |
  | 彻底不要这条绑定 | **删除绑定** | 整行消失（给单字绑的那种行）；内置本来就有的词，按钮写的是「恢复内置」，点了回到内置那枚 |

  改了输入框又后悔：**在列表里再点一下那一行**，两个框就还原成该行的原值（不必先选别的行再选回来）。
- **手改文件**：跑一次 `heinrich-cli emoji reset` 生成带注释的样例，再照样例改：

```toml
[[emoji]]
word = "好评"      # 按词绑：只影响这一个候选
emoji = "👍"

[[emoji]]
code = "vbyg"      # 按码绑：这个码下的候选都跟这枚（vbyg = 好评）
emoji = "👏"

[[emoji]]
word = "开心"
emoji = "😊"
enabled = false    # 停用内置表里的那条：这个词后面不再出现 emoji 候选
```

- 按词绑优先于按码绑；一个词同时命中两者时用按词的那条。
- 不想看 emoji 就在 `config.toml` 里写 `emoji.enabled = false`（一秒内生效，候选里就没有 emoji
  条目了，行宽与没有这个功能时完全一样）。
- 查一查、改错了想重来：

```
heinrich-cli emoji list --limit 20          → 现在生效的映射（含你自己的用户层）
heinrich-cli emoji check --file %APPDATA%\Heinrich\emoji.user.toml
                                            → 校验：词在不在词库、码在不在码表、值是不是单个 emoji
heinrich-cli emoji check                    → 顺带告诉你本机字体能显示多少条（如 2018 / 2395）
heinrich-cli emoji reset                    → 备份用户层（带时间戳）后清空
```

## 万能学习键与多段

- **`z` 查前缀**：忘了某字的后几码时，打到确定的那几位再补一个 `z`。`vbz` 会列出
  `vb` 开头的全部字，**每条都带它自己的五笔全码**（「好 vbg」「好友 vbdc」…）。
  只认末尾的 `z`——`z` 在拼音里是声母，放在中间会和连续拼音打架。
- **`hao'vb` 分段打**：`'` 之前的那一段按拼音、之后那一段按五笔。候选**只出词典里真正存在的词**：
  `hao'ktn` 出「好吃」，`hao'vb` 出「好好」；两段拼不出任何真词时（如 `hao'ni'`）不出候选。
  chip 标在**拼音那个字**的后面：`好[vbg]吃`——告诉你「好」用拼音查的，五笔码是 `vbg`，
  「吃」是用 `ktn` 打出来的。最多两段。句尾再加一个 `'`（`hao'ni'`）表示两段都要拼音。
- 这两条路上屏都**不计入学习分**：多段那次用的码以后再也不会被查，记进去只会污染学习库。
  各段单独打时本来就会各自记分。

## 自定义词组

词表总有跟不上时代的词——「微信」「扫码」「点赞」「健康码」这类，五笔和拼音两份词库
里都没有。你可以自己加：

```
heinrich-cli word add 微信          → 已加入「微信」：拼音 weixin · 码 tmwy · 权重 1700000
heinrich-cli word list              → 词 / 拼音 / 码 / 权重（* = 自动推出来的）
heinrich-cli word rm 微信            → 删掉
heinrich-cli word import 我的词表.txt  → 批量导入（一行一词，可带拼音和码）
```

- **拼音和码都不用自己写**。拼音先从词库里找这个词，找不到就按字拼（「微」wei +
  「信」xin）；码按五笔词组的取码规则从单字全码推出来。想改就加参数：
  `--pinyin waimaixiaoge`、`--code rrtd`、`--weight 5000000`。
- **改完不用重启**。文件在 `%APPDATA%\Heinrich\words.tsv`，server 每秒看一次，
  你下一次按键就生效。也可以直接手改那个文件（`词<TAB>拼音<TAB>码<TAB>权重`，
  后三列可空，`#` 开头是注释）。**例外一处**：如果这个码你在加词之前刚打过，
  输入法会先给你缓存里的旧候选，最多等 3 秒再打就对了。
- **它是普通词，没有特权**。默认权重取同词长词条的中位数，落在同类词的中间，
  所以刚加完不一定排第一条；打一两次，学习分就把它抬上来了。
- **升级不丢**。它不在安装目录里，重装、换版本都不会动它。

不想用命令行就开**设置窗口**——不用去找 exe：

- **任务栏角标**：屏幕右下角输入法图标旁的「亨」小图标（选中亨利五笔时出现），
  **右键 → 设置**；左键是切中英。
- **开始菜单**：按 Win，输入「亨利」，点「亨利五笔 设置」。
- 老办法：安装目录里的 `heinrich-settings.exe`（安装目录下的 `heinrich-setup.exe shortcut`
  可以随时补一个开始菜单快捷方式，不需要管理员）。

> **系统设置里那一行没有「选项」按钮，这是正常现象。** 第三方输入法（含搜狗五笔、小狼毫
> 之外的多数产品）在这页都只有「删除」，按钮只出现在微软自家输入法旁边，条件微软没公开。
> 设置入口用**开始菜单**（见上）。

设置窗口有四页（外观上按钮与选中态会跟随你 Windows 的强调色）：

| 页 | 能做什么 |
|---|---|
| **通用**（默认页） | 码提示时机（mixed / first_time / off）、学习增益 `g`（0–10）、半衰期 `H`（7–365 天）。改完点「应用」，一秒内生效；数字输错时「应用」是灰的，旁边会写清哪里不对 |
| **词组** | 所有自定义词的表 + 编辑框，见下 |
| **emoji** | 哪些词挂了哪枚 emoji（内置 + 你自己加的都在这一张表）：「绑到」+「emoji」两个框填完点「保存绑定」即新增或覆盖，不必先选中一行；点「浏览 emoji…」在分类网格里点一枚；撤销分「停用 / 启用」与「删除绑定 / 恢复内置」；再点已选中的行可还原两个框；「只看我绑的」只列你改过的行；右上角是「停用 emoji 候选」总开关。详见上面「emoji 候选」一节 |
| **学习数据** | 打出过的词按学习分排序（词 / 上屏次数 / 上次使用 / 学习分 / 档位），带搜索；选中一行可以「清除学习分」 |

「恢复默认」是把 `config.toml` 里那三行**删掉**，不是写死当前默认值——这样将来默认值调整时，
你的文件会跟着走。手写在 `config.toml` 里的注释和顺序也**不会**被界面改掉：界面只动它管的那几行。

一张表列出所有自定义词，下面一排编辑框改词 / 拼音 / 码 / 权重——**直接在上面填，点「保存」或
按回车就加入**，不用先点「新增」，保存完面板会自己空出来等下一个词，连着加多少条都不会互相顶掉。
想改已有的词就点表里那一行，它会填进编辑框；改词名也行，保存后旧名字消失、新名字出现。
「删除」删掉选中的那条（还能撤销一次），另有「批量导入…」「打开文件位置」；「清空」在最右边，
只把当前没保存的输入扔掉（Esc 同效）。表里带 `*` 的列是
**自动推出来的、没写进文件**——想要哪一种就在编辑框里填上，填了就不再自动变（换词库升级后
也不会被覆盖）。选中某一行时，编辑框下面会直接告诉你**这个词打什么码**（例如「打字时输 tmwy」），
按那个码打就行。存盘即刻生效（同一个码如果刚打过，最多 3 秒后换成新结果），不用点确定、
也不用重开输入法。

## 学习

排序不是「选过就置顶」，而是一条很平的学习曲线：

```
得分 = 码表权重 + g × ln(1 + 上屏次数 − 1)      g 默认 0.35
```

- **第一次上屏不计分**（`max(0, n−1)`）——偶尔点错一次不会把顺序弄乱。
- **第二次起按次数累积**：用得越多越靠前，但曲线是平的，不会一次跳很远。
- **久不用会退**：45 天半衰期，热点变了顺序也会跟着变回去。
- **连打不跳位**：同一个码连按数字键时那一屏冻住；只有你**提交了别的码**再回来，
  才会看到新顺序。
- 学习数据存在 `%LOCALAPPDATA%\Heinrich\learn.db`（SQLite），只记「哪个词上屏了」，
  不记你打了什么、也不上传。想看具体是哪些词被学上去了：设置窗口 → **学习数据**页；
  某个词想让它退回码表位置，选中它点「清除学习分」（次数与时间清零，你抑制的档位保留）。

近同分的两个词会在第一、第二之间来回几次，这是纯分数比较的必然结果：
分差小于「一次上屏加的分」时，按一下就换位。把 `g` 调小会更稳。

## 配置

`%APPDATA%\Heinrich\config.toml`，**缺文件就全用默认值**。改完不用重启，一秒内生效。

```toml
config_version = 1

# 码提示：mixed（默认，拼音段总是提示）| first_time（只提示还没上过屏的词）| off
hint.mode = "mixed"

# 学习增益。调大 = 学得快、跳得多；0 = 完全不学习（永远按码表顺序）
ranking.learning_gain = 0.35

# 半衰期（天）。想让旧习惯更快退场就调小
ranking.half_life_days = 45

# emoji 候选。false = 候选里不出现 emoji 条目（行宽回到没有这功能时的样子）
emoji.enabled = true
```

写错一行只会被跳过并记一条日志，不会让输入法起不来。码提示与两项学习参数
也可以不开编辑器改：设置窗口 → **通用**页，改完点「应用」（写盘时保留你手写的注释与顺序）。
`emoji.enabled` 在设置窗口 → **emoji** 页右上角的「停用 emoji 候选」开关里，也可以直接手改这一行。

「恢复默认」= 删掉这三行，缺行即取内置默认。

## 已知限制

- **只有 Windows x64、只有五笔 86 版**。32 位程序里用不了（需要另一份 32 位 DLL）。
- **提权后的窗口可能打不了字**：Windows 的 UIPI 不允许低权限进程往高权限窗口注入。
  这是系统行为，不是缺陷。
- **设置窗口只有浅色外观**，不跟随 Windows 深色模式（强调色跟随系统，按钮和选中态会跟着变；
  深色配色留到后面做）。
- **不提供逐字拆解**（「好 = 女 + 子」）：公开的拆字数据是部件级、不是字根级，
  实测重编码一致率只有 1.19%。所以只给码、给键位，不猜拆法。
- 未知码不会联想或纠错，原样吐字母——这是刻意的，宁可不猜也不错字。
- **引擎进程不在（闲置 30 分钟后自动退出）或刚开一个新程序时，第一下可能没有候选窗**：
  引擎侧要先连上 / 装载词库（约 0.1 秒），而按键路径按设计不等待——宁可这一下慢，
  也不要让系统等你。**已输入的编码不会丢**：引擎连上的瞬间，候选窗会自动补弹出来
  （不用再按下一个键）；如果你已经打完且不想等，按空格也能直接上屏正确的字。

## 日志与排障

日志在 `%LOCALAPPDATA%\Heinrich\logs\`，一天一个文件：

- `tsf-20261023.log` —— 输入法在宿主程序里的动作（激活、按键、候选窗、语言栏）
- `server-20261023.log` —— 常驻引擎的动作（装载词库、连接、退出）

如果你在开发机上跑过 `cargo test`，还会看到 `tsf-test-20261023.log`：那是单元测试
自己构造语言栏时的输出，和真机日志分开写，`tsf.ps1 log` 默认不看它。

默认 `info` 级，只写本机，可以随时关掉。**保留最近 7 天**，更早的自动清除；
单个文件写满 32 MiB 就停到第二天（避免某个循环故障把磁盘写爆）。
每一行都对应一次真实触发，不做合并——所以「发生了几次」可以直接数出来。

```powershell
# 看最新一天的日志尾部
powershell -ExecutionPolicy Bypass -File tools\tsf.ps1 log

# 每个日志文件多大
powershell -ExecutionPolicy Bypass -File tools\tsf.ps1 log size

# 立刻清掉 7 天前的（不用等自动清理）
powershell -ExecutionPolicy Bypass -File tools\tsf.ps1 log clean
```

要看逐键级的细节，先 `debug on`，**然后重启要观察的程序**（日志级别在每个进程里只解析一次），
查完记得 `debug off`——忘了关会让日志很快变大。

```powershell
powershell -ExecutionPolicy Bypass -File tools\tsf.ps1 debug on
powershell -ExecutionPolicy Bypass -File tools\tsf.ps1 debug off
powershell -ExecutionPolicy Bypass -File tools\tsf.ps1 debug status
```
