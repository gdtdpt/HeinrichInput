# 亨利五笔 1.1.4

> 发布日期：2026-10-28　|　安装包：`HeinrichSetup-1.1.4.exe`　|　类型：PATCH（修候选窗位置，续 1.1.2）

## 修复

### 候选框不再飞到「十几分钟前的地方」

1.1.2 让候选框「多量一次再摆」，以为这就够了。真实情况更顽固：候选框会跳回**同一个输入框里
十几分钟前打字时的位置**——同一行、横向偏出几百像素，看上去像凭空飞到句子中间。

根因是宿主程序（WorkBuddy、微信、浏览器等）内部缓存的光标位置**没有跟着刷新**。我们把三条途径
（选区、组合串、窗口插入符）全问了一遍，得到的都是同一个旧值——因为它们读的是同一份缓存。
所以「多量几次」「换个问法」这条路走不通：错得很一致，量一百次也还是一致的错。

判断只能换一种方式：**这次量到的位置，和上一次确定正确的位置对得上吗？**

现在的做法：

- **记住上一次确定正确的位置**。每次量到新位置都要先跟它「对得上」才采信——在同一个输入框里，
  插入符不可能一个键就跳出去几百像素（打一个字才挪二三十像素）。
- **第一次按键时做一次直接对照**：在把编码写进输入框**之前**先量一次（那时宿主排版是干净的），
  写完再量一次；两次差到两行高以上，就信写之前那个。这一条是挡住本次事故的关键。
- **对不上时窗口不跟着跳**，留在上一次的位置；随着你继续上屏，它按字数**慢慢往前挪**，
  不会僵在原地。等宿主报出真实位置，它立刻归位。
- **你主动移动光标时一律放行**：方向键、Home / End、PgUp / PgDn、Ctrl+A、Ctrl+Z，以及用鼠标
  点到输入框里的别处。这些情况下窗口立刻跟过去。
- **删掉一段再打字**（全选替换、退格删到行首、Ctrl+X 剪走）：光标从行尾跑回行首，几百像素，
  一律放行——这是最常见的编辑动作，不能拦。
- **万一某程序用我们看不见的方式挪了光标**（脚本跳转、特殊编辑器的按键移动），连续三次报
  同一个位置就会被认可，最多落后三个键。

内部在这一版里迭代了两轮：第一轮的闸门规则被「按过什么键」「鼠标在附近」「像换行」这些
**推测**抢先，反而把同一瞬间里正确的那个值挡掉了。三处真机现场，写前量到的都是对的，
写完量到的都是错的，而闸门选了错的：

| 现场 | 写组合串之前量到 | 写完之后量到（被采纳） | 真实位置 | 谁放行的 |
|---|---|---|---|---|
| 16:00:51 | 898（对） | 1214（剪切之前的旧值） | 914 | Ctrl+A 留下的「放行」 |
| 16:05:10 | 898（对） | 1780（旧值） | 912 | 鼠标停在旧位置上 |
| 15:45:35 | 898（对） | 1504（旧值） | ~910 | 纵向差 58px 被当成「换行」 |

于是判定顺序调整为：**先看写前 / 写后对不对得上**，再谈其他旁证；「换行」不再免检横向
（换行是合理的，但真正换行不会让插入符在同一瞬间往右跳 600px）；「放行」也分了两类——
方向键是真的把光标挪了，放行条留到被用掉为止；Ctrl+A、Esc 只是**推测**下一个键会让光标跳，
中间插进来另一个 Ctrl 组合就作废。

取舍说明：宿主一直报错位置时，窗口会**落后几个像素**而不是停在精确位置。这是有意选的
——「落后」比「飞走」轻得多，而且看得懂。

## 升级说明

- 直接运行 `HeinrichSetup-1.1.4.exe` 覆盖安装即可，用户数据（学习库、自定义词组、emoji 绑定）全部保留。
- 不需要关闭正在运行的程序，也不需要重启电脑；已开着的程序仍在跑旧 DLL，重启它们即切换到新版。
- 可在「设置」窗口标题栏确认版本号（应显示 `亨利五笔 · 设置 · v1.1.4`）。

## 完整变更

| 类型 | 内容 |
|---|---|
| 修复 | 候选框位置：新增位置闸门（`gate.rs`），量到的坐标必须从上次可信位置「走得到」才采纳 |
| 修复 | 首键仲裁：写组合串前后的两次测量差 > 2em 时采用写前那个（排版干净时的值） |

| 修复 | 仲裁的唯一例外：写前值落在编辑区之外时不仲裁（那才是真的换了输入框） |
| 修复 | 「换行」不再免检横向：只允许往左或往右一个小字宽 |
| 修复 | 同行往左跳（删段、全选替换、回行首）放行，避免删完一段后窗口冻在行尾 |
| 修复 | 放行分 `Happened` / `Predicted` 两类；后者遇到另一个 Ctrl 组合作废 |
| 修复 | 拒绝期间按上屏字宽慢跟随，窗口不再僵在原地，也不再跟着错值飞走 |

| 新增 | 四个「光标被挪走」的重置信号：移动键、换行、换编辑区、鼠标指针邻近 |

| 内部 | `Gate::note_other_key(ctrl_chord)`：只由 Ctrl 组合键作废预测性放行 |
| 测试 | 闸门 17 条单测（含 16:00:51 事故的回放用例）；`clippy -D warnings` 干净、`cargo test --all` 全绿 |
