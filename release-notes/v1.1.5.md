# 亨利五笔 1.1.5

> 发布日期：2026-10-29　|　安装包：`HeinrichSetup-1.1.5.exe`　|　类型：PATCH（修任务栏图标消失，续 1.1.4）

## 修复

### 任务栏的「亨」不再消失

1.1.4 发布当天又抓到一个老毛病的新形态：任务栏角标本来的两个图标——系统的输入指示器
（显示亨利的注册图标）和我们自己的中英状态格——在「打开设置改点东西再关掉」之后就
**只剩一个**，而且不自己回来。

排查下来（加了四轮观测、装了四个自测包），事实是这样的：

- 图标并没有被删掉——系统列表里它还在、状态正常、句柄有效，唯独**不画了**；
- 是系统在焦点切换时把它从任务栏布局里**悄悄拿掉了**，且不发任何通知；
- 「画没画」没有任何接口可以查询，所以之前只能在旁边看着。

修法：把恢复动作挂在一个之前从没用过的事件上——**线程焦点**。别的窗口抢走前台再回到
你的窗口时，输入法会收到一次「焦点回来了」的通知，我们就趁这一瞬强制系统重画那一格。
实测从设置界面切到别的输入法再切回来，图标**立刻恢复**，不需要任何等待或操作。

顺带一提：装机对照发现**搜狗五笔也有同样的一瞬消失**——这说明这是所有把图标放进
系统语言栏的输入法的共同毛病，不是亨利独有的实现错误；区别只是我们把它自动修好了。

同时移除了排查期间临时加的后台定时巡检——修复走事件驱动，不需要定时器。

## 升级说明

- 直接运行 `HeinrichSetup-1.1.5.exe` 覆盖安装即可，用户数据（学习库、自定义词组、emoji 绑定）全部保留。
- 不需要关闭正在运行的程序，也不需要重启电脑；已开着的程序仍在跑旧 DLL，重启它们即切换到新版。
- 可在「设置」窗口标题栏确认版本号（应显示 `亨利五笔 · 设置 · v1.1.5`）。

## 完整变更

| 类型 | 内容 |
|---|---|
| 新增 | 语言栏条目存活巡检：焦点变化、激活、线程焦点变化时采样「条目还在不在系统列表里」 |
| 新增 | 线程焦点保单：`ITfThreadFocusSink::OnSetThreadFocus` 时强制系统重画图标（只重画那一格，与模式切换同一条安全路径） |
| 新增 | 巡检读数带「格主」与「上次要图标」，条目被系统摘除时记 error 级日志 |
| 修复 | 「打开设置 → 改配置 → 关设置 → 回宿主」后图标消失且不恢复的问题 |
| 移除 | 排查期间临时引入的 20 秒定时巡检与图标保单定时器（改走线程焦点事件） |
| 内部 | `ICON_KEEP` 图标保留池 16 → 64，绝不销毁系统可能还在显示的句柄 |
| 版本 | 1.1.4 → 1.1.5（PATCH：修任务栏图标显示，无新增输入法能力） |
