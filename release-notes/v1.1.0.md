# 亨利五笔 1.1.0

> 发布日期：2026-10-28　|　安装包：`HeinrichSetup-1.1.0.exe`　|　类型：MINOR（新增用户可见能力）

## 新增

### 引擎重连后候选窗自动补弹（D101）

此前有一个已知空档：刚开一个新程序（或引擎被杀、改动设置触发重载）后立刻打字，头几下「按了键、进了缓冲、但候选框不弹」——按键路径按设计不等待引擎，而此前只能等你按下**下一个键**才恢复显示。如果你恰好把编码打完了（比如四码词组 `dgip` → 感觉），没有下一个键可按，候选窗就一直不出现。

本版本修复：**引擎重连成功的瞬间，如果缓冲里还有没上屏的编码、且当前没有候选窗，就自动补一次查询并把候选窗弹出来**。

- 词组、单字、拼音混输全部覆盖——不依赖任何内置码表；
- 已显示的候选窗不会被替换（所见即所得不变）；
- 键入路径零新增等待：补弹发生在引擎连上之后，不影响正常打字速度。

同时移除了开发过程中试验的「内嵌应急简码表」方案（未发布过，对用户无影响）。

## 修复

### emoji 页可以给自己加的词绑定了（D102）

以前在「词组」页加的自定义词（比如「小红书」）打得出来，回到 emoji 页绑定却被拒绝，提示「不在词库里」——校验只看内置词库，看不见你自己加的词。现在两页看的是同一份词库：**先在「词组」页加词、保存，再回来就能绑**，保存后立刻生效，不必重开窗口。

拦截提示也改了说法，直接告诉你去哪加词。

## 升级说明

- 直接运行 `HeinrichSetup-1.1.0.exe` 覆盖安装即可，用户数据（学习库、自定义词组、emoji 绑定）全部保留。
- DLL 有更新：安装后需要**重启正在打字的应用**（或注销重登）才会生效。
- 可在「设置」窗口标题栏确认版本号（应显示 `亨利五笔 · 设置 · v1.1.0`）。
