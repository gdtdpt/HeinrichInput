# 亨利五笔 1.1.0

> 发布日期：2026-10-28　|　安装包：`HeinrichSetup-1.1.0.exe`　|　类型：MINOR（新增用户可见能力）

## 新增

### 应急简码兜底（D100）

输入法引擎（server）短暂不可用时——最典型的是**新开应用后立刻切换到亨利五笔**的那一瞬间——此前会有一小段「按了键、进了缓冲、但候选框不弹」的空档，只能盲打后靠空格上屏。

本版本在输入法前端（DLL）内嵌一份极小的应急词库（一级简码 25 条 + 二级简码 616 条，共 641 个单字，约 10 KB）：

- server 无应答且已输入 **1–2 码**时，仍能出字并弹出候选窗，不再出现「无反馈空档」；
- server 彻底挂掉期间，一级/二级简码照常能打；
- 应急上屏的词照常计入学习数据（server 恢复后自动补记）。

**边界**（设计取舍）：三码及以上的全码字、词组、拼音、emoji 不在兜底范围内；应急候选不含个性化学习排序。连接恢复后由下一次按键自然接管，无需任何操作。

## 升级说明

- 直接运行 `HeinrichSetup-1.1.0.exe` 覆盖安装即可，用户数据（学习库、自定义词组、emoji 绑定）全部保留。
- DLL 有更新：安装后需要**重启正在打字的应用**（或注销重登）才会生效。
- 可在「设置」窗口标题栏确认版本号（应显示 `亨利五笔 · 设置 · v1.1.0`）。
