# 亨利五笔 1.0.1

> 发布日期：2026-10-28　|　安装包：`HeinrichSetup-1.0.1.exe`　|　类型：PATCH（修复，覆盖安装即可）

## 修复

### 组合态内 Shift+字母的行为（D97 / D98）

- 缓冲非空时按 Shift+字母，大写字母现在会**原样进入缓冲但不匹配任何候选**（如 `gA` 两码都在缓冲里、无候选，单击 Shift 后 `gA` 直接上屏）；此前会被错误地降为小写参与匹配。
- 大写字母匹配不到候选是设计内行为：词库装载保留大写容错，查询入口对含大写的串一律返回空。

### 新进程 / 改设置后的首键卡顿（D99）

- 新应用里切到亨利五笔、或在设置窗口改动后，第一次查询会触发词库整份重载（实测自定义词库约 114ms），期间候选窗不弹。
- 根因：重载函数不写回文件指纹，1 秒节流失效，每次首查都空转重载。修复后重载前先记指纹，节流真正生效。
- 这属于进程外引擎架构的设计内降级（键路径永不等待），本版消除的是节流失效造成的重复重载。

## 变更

- 中文态 `Shift+6` 输出单个 `…`（此前为其他行为，D96）。
- 移除候选排序的「置顶」档位（D95，descope）：学习数据页只剩「抑制」一档，档位列显示与清除学习分文案同步更新。

## 新增（工程侧，不影响使用）

- 版本号规则（§10.1–10.3）：产品版本唯一来源 `Cargo.toml`，只在对外交付时进位。
- `tools\release.ps1` 一键发版脚本（改版本 → 全量校验 → 构建 → 提交 → 打 tag）。
- 设置窗口标题显示版本号（`亨利五笔 · 设置 · v1.0.1`），重装后可一眼确认装的是哪版。

## 升级说明

- 直接运行 `HeinrichSetup-1.0.1.exe` 覆盖安装，用户数据全部保留；安装后重启正在打字的应用生效。
